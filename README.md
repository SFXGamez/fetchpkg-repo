# Download/Install
Download the zip from the latest release.
extract it then open your terminal.
cd into the zip folder then run **python installer.py ./fetch.py**
then wait.
then once its done run **fetch --version** it should print: FETCH: 1.4.3
if it says command not found make sure you have python installed.
or contact me.
